Research tooling should preserve the route from a source to a checkable conclusion, not merely make a workspace look sophisticated. This working note proposes a small kit for source capture, isolated experiments, diffs, and measurement records. The recommendations are a workflow to evaluate; no comparative productivity study or tool benchmark has been performed.

## The list so far

- A reviewed command record with source/input hashes and environment details; shell history alone neither ensures repeatability nor protects secrets.
- One scratch repository per long read, with the harness committed beside the notes.
- A diff viewer I actually like. This matters more than it should.

## Reproduction playbook

**Proposed evaluation.** No new experiment is reported by this editorial revision.

1. Choose a non-sensitive reading task and save its source URL/version plus the question being tested. Start with text notes and version control; do not add an integration unless it preserves a concrete missing artifact.

2. If execution is necessary, use a disposable environment with no production credentials. Save reviewed commands, dependency versions, inputs and outputs in a small evidence directory; redact tokens and private paths before sharing.

3. Ask another reader to repeat the conclusion from the recorded artifacts. Record missing steps and the cost of maintaining the kit before recommending another tool; distinguish a failed reproduction from an editor preference.

## Pre-publication audit

- [ ] Histories and logs are reviewed for secrets before retention or publication.
- [ ] Execution environments and source versions are recoverable, not just shell commands.
- [ ] Recommendations identify an evidence-preservation task rather than a brand preference.

## Verdict

Prefer the smallest tool set that preserves sources, decisions and reproducible outputs. Treat this as a published working note, not a completed comparative tool evaluation. An honest gap in the evidence is more useful than a finished-looking list that another reader cannot use.
