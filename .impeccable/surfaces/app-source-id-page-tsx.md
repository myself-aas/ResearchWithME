# Canonical Source Record

Mode: Read

## Purpose
Inspect a canonical paper, preprint, repository, or dataset record with preserved version history, integrity notices, extracted evidence units, and community reviews.

## First useful result
A researcher verifies source provenance, checks integrity history, and navigates directly to extracted evidence or starts a new review.

## Direction
Present integrity status and preserved versions clearly before dependent records, with direct links to review or save the source.

## Constraints
- WCAG 2.1 AA contrast, visible keyboard focus, and semantic landmarks.
- Reflow cleanly to 360px without horizontal overflow.

## Checks
Retraction/correction notice prominence, version list, extracted evidence locators, and review-this-source link.
