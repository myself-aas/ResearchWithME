# Authors Directory

Mode: Operate

## Purpose
Find a verified domain specialist and understand their expertise.

## First useful result
A visitor filters the directory and opens a credible author profile.

## Direction
Use familiar search and filter controls with the editorial type and palette. Verification state is conveyed by text plus icon, never color alone.

## Constraints
- WCAG 2.1 AA contrast, visible keyboard focus, and semantic landmarks.
- Reflow to 320px without horizontal scrolling.
- No kickers above headings, gradient text, glass as decoration, nested cards, or intrusive pop-ups.
- Loading, empty, error, disabled, and success states explain what happened and what to do next.
- Local assets and honest demo labels; no fabricated live verification claims.

## Checks
Empty search, credential filters, long names, contrast, focus, and mobile card stacking.
