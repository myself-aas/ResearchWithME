# Structured Claim Detail

Mode: Evaluate & Audit

## Purpose
Present a canonical Claim's multi-dimensional trust dimensions (review, replication, certainty, consensus), normalized ClaimEvidence links, and independent Claim Assessments.

## First useful result
A researcher audits supporting, qualifying, and contradicting evidence records anchored to source versions alongside structured confidence assessments.

## Direction
Dimensioned scholarly evaluation grid using semantic tokens with zero composite vanity scores.

## Constraints
- WCAG 2.1 AA contrast and accessible definition lists.
- Show every opposing or qualifying evidence link clearly.

## Checks
Four-dimension trust summary, normalized ClaimEvidence list, assessment rationale display, and breadcrumb navigation.
