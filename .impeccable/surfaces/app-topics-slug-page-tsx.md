# Canonical Topic Detail

Mode: Browse & Discover

## Purpose
Expose a dedicated canonical topic landing page listing child taxonomy topics, tagged contributions, active research projects, and open-source tools for a given slug.

## First useful result
A researcher explores all contributions, projects, and tools linked to a canonical topic and traverses parent/child taxonomy relationships.

## Direction
Calm multi-section index using semantic surfaces and concise cross-object counts.

## Constraints
- WCAG 2.1 AA contrast and breadcrumb navigation back to `/topics`.
- Clean responsive reflow from 320px to 1920px.

## Checks
Child topic navigation, filtered contributions/projects/tools lists, and feed/graph deep links.
