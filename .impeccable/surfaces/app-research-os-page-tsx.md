# Personal Research OS Hub

Mode: Operate

## Purpose
Unify action-required Attention items, event-history Notifications, optional AI Assistant Tasks, Research Goals, Event-Derived Scholarly Recognition, and Dashboard Landing Preferences while enforcing their semantic boundaries.

## First useful result
A researcher resolves an open Attention item, marks a Notification read independently, explicitly promotes an optional Assistant Task into the Attention Queue, and configures default landing & topic follows.

## Direction
Keep each v3.4 §10/§11/§14 subsystem visibly labeled and functionally separated: assistant tasks never create mandatory attention automatically, and recognition shows verifiable event counts with zero composite vanity scores.

## Constraints
- WCAG 2.1 AA contrast, semantic sections/landmarks, and accessible progress bars paired with textual ratios.
- Reflow cleanly to 360px without horizontal overflow.
- Never display composite reputation or trust scores.

## Checks
Attention item resolution, independent notification read toggle, explicit assistant task promotion, recognition event breakdown, and landing preference persistence.
