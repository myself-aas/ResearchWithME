## Message

Subject: Pre-approval question: two downloadable manuscript-checking programs

Hello,

I run the store for ResearchWithMe (https://researchwith.me), a free archive of research reviews. The store has no
products yet. Your prohibited-products page asks sellers to check before selling when unsure, so I would like to
confirm two digital downloads before I list them.

Each is a zip file containing a small program (Python source), a PDF user guide, and templates. The buyer
downloads it once and runs it on their own computer. Nothing is uploaded to me, no person reads or comments on
the buyer's document, and neither program writes, rewrites, or generates any text. Neither uses a language model.

1. Manuscript Check (one-time price, about $12)
   The buyer runs the program on their own research manuscript. It applies fixed rules and writes a report:
   which standard sections and declarations are present, citations that do not match the reference list,
   reported p values that do not match their test statistic, numbers in the abstract that are missing from the
   body, figures and tables cited without a caption, undefined abbreviations, and very long sentences. It also
   lists the first sentence of each paragraph and the sentences that make claims, for the author to review.
   The report states that it is produced by software and is not peer review. It suggests no wording.

2. Response-to-Reviewers Check (one-time price, about $9)
   An author revising a paper runs the program on the reviewers' comments and the response letter the author
   has already written. It lists every reviewer comment and marks whether the letter quotes it and has a
   response under it. It does not draft, complete, or reword the response. The download also has an empty
   letter template and a tracking spreadsheet.

My questions:

a) Are these acceptable as software downloads, and not treated as "Services of any kind"?
b) Does either fall under "Homework/Essay mills"? They only check a document the buyer wrote and never generate
   or alter text.
c) Is there any wording you would want on, or kept off, the product pages?

I can send the zip files or a sample report.
