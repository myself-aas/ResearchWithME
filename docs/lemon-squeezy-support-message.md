## Message

Subject: Pre-approval question: a downloadable manuscript-checking program

Hello,

I run the store for ResearchWithMe (https://researchwith.me), a free archive of research reviews. The store has no
products yet. Your prohibited-products page asks sellers to check before selling when unsure, so I would like to
confirm one digital download before I list it.

The product is called Manuscript Check and would cost $5, paid once. It is a zip file containing three small
programs (Python source), PDF user guides, a Word template, and a spreadsheet. The buyer downloads it once and
runs the programs on their own computer. Nothing is uploaded to me, no person reads or comments on the buyer's
document, and no program writes, rewrites, or generates any text. None uses a language model. A free edition
with fewer checks is offered on my own site, outside the store.

1. The first program reads the buyer's own research manuscript and writes a report by fixed rules: which
   standard sections and declarations are present, citations that do not match the reference list, reported
   p values that do not match their test statistic, numbers in the abstract that are missing from the body,
   figures and tables cited without a caption, undefined abbreviations, and very long sentences. It also lists
   the first sentence of each paragraph and the sentences that make claims, for the author to review. The
   report states that it is produced by software and is not peer review. It suggests no wording.

2. The second program looks up each entry of the buyer's reference list in two public indexes (Crossref and
   OpenAlex) and reports which were found, which differ from the index record, and which are marked retracted.
   It never adds or suggests a reference.

3. The third program is for an author revising a paper. It lists every comment in the journal reviewers'
   reports and marks whether the response letter the author has written quotes it and has a response under
   it. It does not draft, complete, or reword the response.

My questions:

a) Is this acceptable as a software download, and not treated as "Services of any kind"?
b) Does it fall under "Homework/Essay mills"? It only checks documents the buyer wrote and never generates or
   alters text.
c) Is there any wording you would want on, or kept off, the product page?

I can send the zip file or a sample report.
