Investigate the Next response and rerun in a configured environment; do not interpret these failures as passes. The API-example keyboard regression did pass against Next.

## Release blockers and remaining work

Retired `/papers`, `/paper/:slug` and `/editions` routes are explicitly checked for 404; article grid, filtering and bookmark persistence use isolated network fixtures, not production demo data. The editor page now has the shared shell and a focusable main landmark. The reduced-motion check permits only near-zero-duration CSS transitions. These tests do not establish live CMS or authenticated integration behavior.

Entry-point regression tests mock Supabase HTTP and check published reads, draft isolation, editor/reader/anonymous authorization and missing configuration.
