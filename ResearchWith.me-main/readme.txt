The WordPress theme for ResearchWithMe, based on Neve by ThemeIsle.

== Description ==
ReMe is the WordPress theme for ResearchWithMe. It is a fast, accessible theme for publishing research, with a drag-and-drop header and footer builder, global colors and typography, per-page layout settings and full block editor support.

ReMe is a fork of the Neve theme (version 4.2.17) by ThemeIsle. Compared with Neve it has no upsells, no usage tracking, no ThemeIsle SDK, no Neve Pro integration and no WooCommerce support.
