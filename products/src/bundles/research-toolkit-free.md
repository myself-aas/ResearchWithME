# Research Toolkit

Free tools for the chores around a manuscript: tables, formatting, and choosing a journal.

ResearchWithMe, version 1.0

## What is in this download

| Folder | What it is | What you need | Guide |
| --- | --- | --- | --- |
| tables | The free edition of a program that turns a CSV file into APA-style statistical tables: descriptive statistics, correlation matrices, and t tests | Python 3.8 or later | Statistical-Table-Generator.pdf |
| formatting | Four Word templates and a pre-upload checklist | Word, or an editor that opens .docx | Manuscript-Formatting-Kit.pdf |
| journals | A workbook for comparing candidate journals on your own criteria | Excel, or an editor that opens .xlsx | Journal-Shortlist-Workbook.pdf |

Everything here is free. There is no account, no sign-up, and no limit on use. The templates and the workbook are complete. The table program is a free edition: ANOVA, chi-square, and regression tables are in the full edition, which is sold separately. You may share this download, unchanged, with anyone.

## Where to start

- You have a data file and need tables: open the tables folder and its guide. The first command to try is `python apa_tables.py describe sample-data.csv --vars age study_hours post_score`.
- You have a manuscript to get into shape: open the formatting folder. If your journal has its own template, use that one; otherwise start from one of these.
- You have not chosen a journal: open the journals folder and read the guide before the workbook.

## What these are not

The table program computes what you ask for; it does not choose an analysis or interpret a result. The templates set layout only and write nothing. The workbook contains no journal data and recommends no journal.

If you want fuller statistics with menus, JASP and jamovi are free desktop programs and do far more than the table program here.
