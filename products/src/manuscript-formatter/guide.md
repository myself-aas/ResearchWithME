# Manuscript Formatting Kit

Word templates and a checklist for getting a manuscript into submission shape.

ResearchWithMe, version 1.0

These are templates you fill with your own text. They change layout only. Nothing in this kit writes, rewrites, or checks your wording.

## Which template to use

1. **If the journal provides its own template, use that.** A journal's template always takes precedence over anything here.
2. If the journal says "APA style" or "follow the Publication Manual", use the APA 7 template.
3. If the journal gives only general instructions (double-spaced, line-numbered, any consistent reference style), use the journal submission template and adjust it to those instructions.

Read the journal's author instructions before you start and again before you upload. Instructions differ on word limits, abstract structure, heading levels, reference style, and where tables and figures go, and they change.

## How to move your text in

Pasting from another document usually brings the old formatting with it. To avoid that:

1. Open the template and save it under a new name.
2. Copy a section from your manuscript.
3. In the template, paste with "Keep Text Only" (Word: Home, Paste, Paste Special, Unformatted Text; or the clipboard icon that appears after pasting).
4. Apply the template's styles from the Styles gallery: Normal for body text, Heading 1 to Heading 3 for headings.
5. Restore italics by hand where they carry meaning: species names, statistical symbols, titles in references.

Apply styles; do not format by hand. If a heading is made bold with the toolbar, Word does not know it is a heading, and changing the look later means changing every one.

## What the APA 7 template sets

| Element | Setting |
| --- | --- |
| Margins | 1 inch on all sides |
| Font | 12-point Times New Roman (APA also accepts 11-point Calibri, 11-point Arial, 10-point Lucida Sans Unicode, and 11-point Georgia) |
| Line spacing | Double throughout, with no extra space between paragraphs |
| Alignment | Left-aligned with a ragged right edge |
| Paragraph indent | First line 0.5 inch |
| Page number | Top right of every page, starting on the title page |
| Running head | Shortened title in capitals, top left; required for professional papers and not for student papers |
| Heading level 1 | Centred, bold, title case |
| Heading level 2 | Flush left, bold, title case |
| Heading level 3 | Flush left, bold italic, title case |
| Abstract | On its own page, heading centred and bold, one unindented paragraph, usually no more than 250 words |
| Keywords | Below the abstract, indented, the label "Keywords:" in italics |
| References | On a new page, heading centred and bold, double-spaced, hanging indent of 0.5 inch |

If you are writing a student paper, delete the running head and replace the author note with the course details your institution asks for.

## What the journal submission template sets

| Element | Setting |
| --- | --- |
| Margins | 1 inch on all sides |
| Font | 12-point Times New Roman |
| Line spacing | Double |
| Line numbers | Continuous through the document |
| Page numbers | Bottom centre |
| Order | Title page, abstract and keywords, main text, declarations, references, tables, figure legends |

To switch line numbers off or restart them on each page, use Layout, Line Numbers in Word.

## Tables and figures

- Build tables with Word's table tool, never with tabs or spaces.
- In APA style a table has a horizontal rule above and below the header row and one at the foot, and no vertical rules.
- Number tables and figures in the order they are first mentioned.
- Most journals want figures uploaded as separate files at a stated resolution, with legends listed at the end of the manuscript. Check the instructions.

## Converting from LaTeX or to PDF

This kit is for Word. If your manuscript is in LaTeX, use the journal's LaTeX class. When a journal asks for a PDF, produce it with File, Save As, PDF, then open the PDF and check that line numbers, special characters, and equations survived.

## What this kit does not do

It does not format references; use a reference manager with the journal's citation style. It does not cover any individual journal's house style. It does not check your manuscript for you; the Manuscript Check does some of that.
