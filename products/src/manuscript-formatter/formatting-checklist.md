# Formatting checklist

Run this before you upload. Tick each item or note why it does not apply. Where the journal's instructions differ, the journal wins.

## The journal's rules

- [ ] Author instructions read again today, not from memory
- [ ] Article type chosen, and its word limit met (check what the count includes)
- [ ] Abstract within the limit and in the required form (structured or unstructured)
- [ ] Number of keywords, tables, figures, and references within the limits
- [ ] Reference style is the one the journal names

## The file

- [ ] Font, size, spacing, and margins as required
- [ ] Line numbers on, if required
- [ ] Page numbers on
- [ ] Headings applied with styles, at the levels the journal allows
- [ ] No tracked changes or comments left in the file (unless it is a revision that asks for them)
- [ ] File type and file name as required

## Anonymised review, if the journal uses it

- [ ] Author names, affiliations, and acknowledgements moved to the separate title page
- [ ] Self-citations written in the third person
- [ ] Author details removed from the file's properties (Word: File, Info, Inspect Document)

## Title page

- [ ] Title, and a short title if required
- [ ] Every author's name, affiliation, and identifier as required
- [ ] Corresponding author with email address
- [ ] Word counts, and number of tables and figures, if required

## Text

- [ ] Every abbreviation defined at first use in the abstract and again in the main text
- [ ] Every citation in the text is in the reference list, and the reverse
- [ ] Every table and figure is cited in the text, in numerical order
- [ ] Units, statistics, and number formats consistent throughout

## Declarations

- [ ] Ethics approval and consent
- [ ] Funding, with grant numbers
- [ ] Competing interests, including a statement if there are none
- [ ] Data and code availability
- [ ] Author contributions
- [ ] Acknowledgements, with permission from those named
- [ ] Use of AI tools, if the journal asks for a statement

## Tables, figures, and other files

- [ ] Tables are real tables, each with a number and a title
- [ ] Figures at the required resolution and format, uploaded as required
- [ ] Figure legends where the journal wants them
- [ ] Permission obtained for anything reproduced from elsewhere
- [ ] Supplementary files named and cited in the text
- [ ] Reporting checklist completed, if required
- [ ] Cover letter addressed to the current editor

## Last look

- [ ] PDF produced by the submission system opened and read page by page
